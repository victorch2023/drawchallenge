Palabras clave

    Jurado en el dispositivo

    SmolVLM 256M, modelo abierto, se descarga una vez en este navegador (~200 MB) y puntúa el dibujo aquí. No hay API key ni cuota.

    Aún no descargado

    Hace falta un navegador reciente (Chrome o Edge). Si hay GPU, la usa; si no, corre más lento en el procesador. La primera vez necesita internet para bajar el modelo. Después funciona con la copia guardada.
